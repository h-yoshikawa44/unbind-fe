# 英文一覧ページ

## 概要

登録済みの英文を一覧表示するページ。各英文の編集・削除、および新規英文の追加を起点とする画面。
英文に付与されたタグを一覧に表示し、タグによる絞り込みに加え、キーワード（英文・和訳）による絞り込みも行える。

## ルート

| 項目                 | 値                                                                                                         |
| -------------------- | ---------------------------------------------------------------------------------------------------------- |
| URL                  | `/`（タグ絞り込み時: `/?tags=過去文,あいさつ文`、キーワード絞り込み時: `/?q=hello world`）                 |
| ページコンポーネント | `src/pages/SentencesPage.tsx`                                                                              |
| UIコンポーネント     | `src/components/SentenceList.tsx`, `src/components/TagInput.tsx`（絞り込みバーは `SentenceList` 内に実装） |

### クエリパラメータ

| パラメータ | 型                 | 説明                                                                                                                                                                                                                                                                                         |
| ---------- | ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `tags`     | カンマ区切り文字列 | 絞り込むタグ。例: `?tags=過去文,あいさつ文`。指定したタグを **すべて含む（AND）** 英文のみ表示する。未指定時は全件表示。`router.tsx` の `validateSearch` で正規化（前後空白の除去・空要素の除外・重複排除）する                                                                              |
| `q`        | 空白区切り文字列   | 絞り込むキーワード。例: `?q=hello world`。空白区切りで複数指定でき、指定したキーワードを **すべて含む（AND）** 英文のみ表示する。各英文の **英文テキストと和訳** を対象に大文字小文字を区別せず部分一致で判定する。未指定時は全件表示。`router.tsx` の `validateSearch` で前後空白を除去する |

`tags` と `q` は併用でき、両方指定時は「タグAND」かつ「キーワードAND」を満たす英文のみ表示する。

## 要素仕様

### リストヘッダー

| 要素           | 種別             | 説明                     |
| -------------- | ---------------- | ------------------------ |
| 英文一覧       | 見出し (`h2`)    | ページタイトル           |
| `+ 英文を追加` | ボタン (primary) | 英文追加ページへ遷移する |

### 絞り込みバー（常に表示）

| 要素                   | 種別           | 説明                                                                                                                                                          |
| ---------------------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `キーワードで絞り込み` | ラベル         | キーワード入力欄の見出し                                                                                                                                      |
| キーワード入力欄       | 検索入力       | 常設。英文テキストと和訳を対象に部分一致（大文字小文字を区別しない）で絞り込む。空白区切りで複数キーワードを AND 指定可                                       |
| `タグで絞り込み`       | ラベル         | タグチップの見出し（付与済みタグが1つ以上ある場合のみ表示）                                                                                                   |
| タグチップ             | トグルボタン   | 登録済みの全英文で使われているタグを50音/アルファベット順に列挙。クリックで選択/解除を切り替え。選択中はハイライト表示。付与済みタグが1つ以上ある場合のみ表示 |
| `クリア`               | リンク風ボタン | 絞り込み中（タグ選択中またはキーワード入力中）のみ表示。すべてのタグ選択とキーワードを解除して全件表示に戻す                                                  |

### 英文アイテム（一覧に英文が存在する場合）

| 要素         | 種別                    | 説明                                                        |
| ------------ | ----------------------- | ----------------------------------------------------------- |
| 英文テキスト | ボタン（行全体）        | クリックで英文詳細ページへ遷移する                          |
| タグ         | チップ（表示のみ）      | 英文に付与されたタグを列挙。タグがない場合は非表示          |
| メタ情報     | テキスト                | `{トークン数} トークン · {最終更新日 (ja-JP)}` の形式で表示 |
| `削除`       | ボタン (danger / small) | 確認ダイアログを表示し、承認で削除する                      |

### 空状態

| ケース                          | 案内テキスト                                 | `最初の英文を追加する` ボタン |
| ------------------------------- | -------------------------------------------- | ----------------------------- |
| 英文が1件もない                 | 「まだ英文が登録されていません。」           | 表示する（primary）           |
| 絞り込み結果が0件（英文はある） | 「絞り込み条件に一致する英文はありません。」 | 表示しない                    |

`最初の英文を追加する` ボタンは英文追加ページへ遷移する（`+ 英文を追加` と同じ動作）。

## ユーザー操作

| 操作                               | 結果                                                                                                         |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `+ 英文を追加` をクリック          | `/sentences/new` へ遷移                                                                                      |
| 英文アイテム本体をクリック         | `/sentences/{id}` へ遷移                                                                                     |
| 未選択のタグチップをクリック       | そのタグを絞り込み条件に追加し、URLの `tags` を更新（例: `/?tags=過去文`）                                   |
| 選択中のタグチップをクリック       | そのタグを絞り込み条件から除外し、URLの `tags` を更新（全解除時は `tags` を除去）                            |
| キーワード入力欄に文字を入力       | 入力内容で即時に絞り込み、URLの `q` を更新（履歴を汚さないよう `replace` で更新。空にした場合は `q` を除去） |
| `クリア` をクリック                | すべてのタグ選択とキーワードを解除し、`/` へ戻す                                                             |
| `削除` をクリック                  | 確認ダイアログを表示                                                                                         |
| 削除確認ダイアログで「OK」         | 英文を削除し、一覧を更新                                                                                     |
| 削除確認ダイアログで「キャンセル」 | 何もしない                                                                                                   |

絞り込み（タグ・キーワード）の状態はURLのクエリパラメータで保持するため、リロード・URL共有に対応する（キーワードは初期表示時に URL の `q` から復元する）。

**削除確認ダイアログのメッセージ例:**

```
"The quick brown fox..." を削除しますか？
```

（英文テキストが40文字を超える場合は末尾を `...` で省略する）

## 画面遷移

```
英文追加ページ (/sentences/new)  ←──┐
                                    │  [+ 英文を追加]
英文一覧ページ (/)  ────────────────┤
                                    │  [英文アイテムをクリック]
英文詳細ページ (/sentences/{id})  ←─┘
```

## ページ状態

| 状態変数            | 型           | 説明                                                                                                                            |
| ------------------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| `sentences`         | `Sentence[]` | 取得済みの全英文。マウント時に `fetchSentences()` で取得                                                                        |
| `selectedTags`      | `string[]`   | 絞り込み中のタグ。URLの `tags`（`useSearch`）から導出                                                                           |
| `keyword`           | `string`     | キーワード入力欄の値。入力の追従性のためローカル `useState` で保持し、初期値は URL の `q` から復元する                          |
| `keywords`          | `string[]`   | `keyword` を空白で分割した検索語の配列（AND 判定に使用）                                                                        |
| `allTags`           | `string[]`   | 絞り込みバー用のタグ候補。`sentences` から重複なしで算出し、50音/アルファベット順にソート                                       |
| `filteredSentences` | `Sentence[]` | `selectedTags` をすべて含み（AND）、かつ `keywords` をすべて英文・和訳に含む（AND）英文のみに絞った表示用リスト。未指定時は全件 |

## API呼び出し

| タイミング | 関数                 | 説明                                                          |
| ---------- | -------------------- | ------------------------------------------------------------- |
| マウント時 | `fetchSentences()`   | 英文一覧を取得して `sentences` にセット                       |
| 削除確認後 | `deleteSentence(id)` | 指定IDの英文を削除。完了後 `sentences` から該当アイテムを除去 |
