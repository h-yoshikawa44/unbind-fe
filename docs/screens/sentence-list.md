# 英文一覧ページ

## 概要

登録済みの英文を一覧表示するページ。各英文の編集・削除、および新規英文の追加を起点とする画面。

## ルート

| 項目                 | 値                                |
| -------------------- | --------------------------------- |
| URL                  | `/`                               |
| ページコンポーネント | `src/pages/SentencesPage.tsx`     |
| UIコンポーネント     | `src/components/SentenceList.tsx` |

## 画面レイアウト

```
┌──────────────────────────────────────────────────────┐
│ [Unbind]  英文分解・翻訳アシスタント                  │  ← 共通ヘッダー
├──────────────────────────────────────────────────────┤
│  英文一覧                        [+ 英文を追加]       │  ← リストヘッダー
│ ──────────────────────────────────────────────────── │
│  The quick brown fox jumps...                         │
│  10 トークン · 2025/07/01              [削除]         │  ← 英文アイテム
│ ──────────────────────────────────────────────────── │
│  She sells seashells by the sea...                    │
│  8 トークン  · 2025/07/02              [削除]         │
│ ──────────────────────────────────────────────────── │
│  ...                                                  │
└──────────────────────────────────────────────────────┘
```

**英文が1件もない場合（空状態）:**

```
┌──────────────────────────────────────────────────────┐
│ [Unbind]  英文分解・翻訳アシスタント                  │
├──────────────────────────────────────────────────────┤
│  英文一覧                        [+ 英文を追加]       │
│ ──────────────────────────────────────────────────── │
│                                                       │
│          まだ英文が登録されていません。                │
│               [最初の英文を追加する]                  │
│                                                       │
└──────────────────────────────────────────────────────┘
```

## 要素仕様

### リストヘッダー

| 要素           | 種別             | 説明                     |
| -------------- | ---------------- | ------------------------ |
| 英文一覧       | 見出し (`h2`)    | ページタイトル           |
| `+ 英文を追加` | ボタン (primary) | 英文追加ページへ遷移する |

### 英文アイテム（一覧に英文が存在する場合）

| 要素         | 種別                    | 説明                                                        |
| ------------ | ----------------------- | ----------------------------------------------------------- |
| 英文テキスト | ボタン（行全体）        | クリックで英文詳細ページへ遷移する                          |
| メタ情報     | テキスト                | `{トークン数} トークン · {最終更新日 (ja-JP)}` の形式で表示 |
| `削除`       | ボタン (danger / small) | 確認ダイアログを表示し、承認で削除する                      |

### 空状態（英文が1件もない場合）

| 要素                   | 種別             | 説明                                                  |
| ---------------------- | ---------------- | ----------------------------------------------------- |
| 案内テキスト           | テキスト         | 「まだ英文が登録されていません。」                    |
| `最初の英文を追加する` | ボタン (primary) | 英文追加ページへ遷移する（`+ 英文を追加` と同じ動作） |

## ユーザー操作

| 操作                               | 結果                     |
| ---------------------------------- | ------------------------ |
| `+ 英文を追加` をクリック          | `/sentences/new` へ遷移  |
| 英文アイテム本体をクリック         | `/sentences/{id}` へ遷移 |
| `削除` をクリック                  | 確認ダイアログを表示     |
| 削除確認ダイアログで「OK」         | 英文を削除し、一覧を更新 |
| 削除確認ダイアログで「キャンセル」 | 何もしない               |

**削除確認ダイアログのメッセージ例:**

```
"The quick brown fox..." を削除しますか？
```

（英文テキストが40文字を超える場合は末尾を `...` で省略する）

## 画面遷移

```
英文追加ページ (/sentences/new)  ←──┐
                                    │  [+ 英文を追加]
英文一覧ページ (/)  ────────────────┤
                                    │  [英文アイテムをクリック]
英文詳細ページ (/sentences/{id})  ←─┘
```

## ページ状態

| 状態変数    | 型           | 説明                                                     |
| ----------- | ------------ | -------------------------------------------------------- |
| `sentences` | `Sentence[]` | 表示中の英文一覧。マウント時に `fetchSentences()` で取得 |

## API呼び出し

| タイミング | 関数                 | 説明                                                          |
| ---------- | -------------------- | ------------------------------------------------------------- |
| マウント時 | `fetchSentences()`   | 英文一覧を取得して `sentences` にセット                       |
| 削除確認後 | `deleteSentence(id)` | 指定IDの英文を削除。完了後 `sentences` から該当アイテムを除去 |
