# 英文追加ページ

## 概要

新しい英文を入力するページ。送信すると英文をスペース区切りでトークンに分解し、英文詳細ページへ遷移する。

## ルート

| 項目                 | 値                                |
| -------------------- | --------------------------------- |
| URL                  | `/sentences/new`                  |
| ページコンポーネント | `src/pages/SentenceNewPage.tsx`   |
| UIコンポーネント     | `src/components/SentenceForm.tsx` |

## 画面レイアウト

```
┌──────────────────────────────────────────────────────┐
│ [Unbind]  英文分解・翻訳アシスタント                  │  ← 共通ヘッダー
├──────────────────────────────────────────────────────┤
│  英文を入力                                           │  ← フォームタイトル
│ ┌────────────────────────────────────────────────┐   │
│ │ 例: The quick brown fox jumps over the lazy    │   │  ← テキストエリア
│ │ dog.                                           │   │
│ │                                                │   │
│ └────────────────────────────────────────────────┘   │
│                          [キャンセル]  [分解する]     │  ← アクション
└──────────────────────────────────────────────────────┘
```

## 要素仕様

### フォーム

| 要素             | 種別                      | 説明                                                                  |
| ---------------- | ------------------------- | --------------------------------------------------------------------- |
| 英文を入力       | 見出し (`h2`)             | フォームタイトル                                                      |
| テキストエリア   | `textarea`                | 英文を入力する。ページ表示時に自動フォーカス (`autoFocus`)。行数は3行 |
| プレースホルダー | テキスト                  | `例: The quick brown fox jumps over the lazy dog.`                    |
| `キャンセル`     | ボタン (outline)          | 英文一覧ページへ戻る                                                  |
| `分解する`       | ボタン (primary / submit) | 英文を送信して分解処理を実行する                                      |

### バリデーション

| 条件                              | 挙動                                   |
| --------------------------------- | -------------------------------------- |
| テキストが空（空白のみを含む）    | `分解する` ボタンを無効化 (`disabled`) |
| テキストが1文字以上（空白除去後） | `分解する` ボタンを有効化              |

送信時にもテキストをトリムし、空の場合は何もしない（二重防止）。

## ユーザー操作

| 操作                                        | 結果                                                 |
| ------------------------------------------- | ---------------------------------------------------- |
| テキストエリアに英文を入力                  | `分解する` ボタンが有効になる                        |
| `分解する` をクリック（またはフォーム送信） | 英文を保存してトークン分解、`/sentences/{id}` へ遷移 |
| `キャンセル` をクリック                     | `/` へ遷移                                           |

## 英文分解処理フロー

1. テキストをトリムして `onSubmit(text)` を呼び出す
2. `crypto.randomUUID()` で新しい英文IDを生成
3. `tokenize(id, text)` でスペース区切りのトークン配列を生成（各トークンはランダムUUID付与）
4. `createSentence(text, tokens, id)` でlocalStorageに保存
5. 作成した英文の `/sentences/{id}` へリダイレクト

## 画面遷移

```
英文一覧ページ (/)  ──[+ 英文を追加]──→  英文追加ページ (/sentences/new)
                                             │
                           [キャンセル] ─────┤
                                ↓            │ [分解する]
                          英文一覧 (/)        ↓
                                       英文詳細ページ (/sentences/{id})
```

## ページ状態

ページ自体はステートレス。フォームの入力状態は `SentenceForm` コンポーネントが内部で保持する。

| 状態変数 | 型       | コンポーネント | 説明                   |
| -------- | -------- | -------------- | ---------------------- |
| `text`   | `string` | `SentenceForm` | テキストエリアの入力値 |

## API呼び出し

| タイミング     | 関数                               | 説明                                                                 |
| -------------- | ---------------------------------- | -------------------------------------------------------------------- |
| フォーム送信時 | `createSentence(text, tokens, id)` | 英文と初期トークンをlocalStorageに保存し、作成した `Sentence` を返す |
